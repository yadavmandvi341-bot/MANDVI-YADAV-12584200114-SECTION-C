## Quick Start

### Tasks 1–7 (HTML / CSS / JS & Live External APIs)
Open `index.html` in the root folder or open any task's `index.html` directly in your browser:
- `01_concentric_circles/index.html` — 3 concentric circles (10px, 20px, 30px radii)
- `02_ten_horizontal_cards/index.html` — 10 horizontally aligned cards with top images
- `03_todo_list/index.html` — To-Do list with Delete, Move Up, Move Down, and Checkbox
- `04_dynamic_chessboard/index.html` — Chessboard with all HTML elements & CSS styles created dynamically in JS
- `05_snake_and_ladder/index.html` — Playable 2-player Snake & Ladder game
- `06_random_jokes_api/index.html` — Random Jokes fetcher (JokeAPI v2 + Official Joke API fallback)
- `07_universities_by_country_api/index.html` — Country Universities finder (Hipolabs API + Hipo HTTPS JSON fallback)

### Tasks 8–12 (Node.js + Express + MongoDB)
Inside each folder (`08_*` through `12_*`), run:
```bash
npm install
npm start
```
Default ports:
- **Task 8** (`08_express_5_routes_ejs`): `http://localhost:3008` (7 GET/POST routes + EJS)
- **Task 9** (`09_express_restful_crud`): `http://localhost:3009` (RESTful Product CRUD + JSON API)
- **Task 10** (`10_express_product_api_csr`): `http://localhost:3010` (Product API + Client-Side Rendering)
- **Task 11** (`11_express_mongodb_crud`): `http://localhost:3011` (Express + Mongoose MongoDB CRUD; auto-falls back to `products_fallback.json` if MongoDB is not running)
- **Task 12** (`12_ecommerce_fullstack`): `http://localhost:3012` (**MandviMart** Full-stack E-Commerce: Real Product Photos, Cart, Payment, Orders, Seller Master Panel)
